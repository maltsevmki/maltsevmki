## About me

I build AI products end to end: React and Next.js frontends, Python services, LLM pipelines, and the evaluations that keep them reliable in production.

- **Founder of [Mnema](https://mnema.me)**, an AI study app that turns lecture slides, PDFs, handwritten notes and recordings into flashcards and quizzes, each citing the page, slide or minute it came from.
- **Senior Software Engineer at HS-Soft** (Switzerland, remote): self-serve sales forecasting, internal platforms, release pipelines.
- **Computer Science at PJATK**, Warsaw.

## What I work on

- **Tool-calling agents** that plan a study set in chat, research the web, read files and write cards, with a trust check on every source
- **Vision pipelines** for slides, diagrams and handwriting: image-occlusion label recall from **73% to 98%** on a 16-diagram benchmark
- **Evaluation harnesses** with LLM judges: 350+ scenarios and 7,000+ backend tests behind every release
- **Spaced repetition**: Anki import that keeps the full review history and moves SM-2 schedules to FSRS-6
